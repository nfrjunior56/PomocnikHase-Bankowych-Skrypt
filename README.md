Czego potrzebujesz, żeby odpalić projekt:
Pobierz Pythona: Jeśli jeszcze go nie masz, ściągnij instalator ze strony python.org.
Otwórz Terminal: Kliknij prawym przyciskiem myszy na folder, w którym znajduje się pobrany Skrypt.py i wybierz opcję "Otwórz w terminalu" (Open in Terminal).
Uruchom magię: W czarnym okienku wpisz poniższą komendę i wciśnij Enter: python3 PomocnikHase-Bankowych-Skrypt.py
Poradnik wyżej opisany jest uniwersalny dla środowiska Windows oraz Linux
